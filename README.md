# Community Directory

A community-maintained directory to help members find and connect with others who share similar interests, skills, and experience levels.

Whether you're looking for help with Microsoft 365, Azure, Home Assistant, Linux, networking, cybersecurity, or simply want to meet other community members in a similar timezone, this directory makes it easier to find the right people.

---

## How It Works

1. Open the **Issues** tab.
2. Select **Member Directory Registration**.
3. Complete the registration form.
4. Submit your profile.
5. Community members can browse registrations and connect through Discord.

---

## Directory Categories

Members can identify skills and interests in areas such as:

- Microsoft 365
- Azure
- Programming
- Linux
- Networking
- Home Assistant
- Cyber Security

Profiles also include:

- Discord handle
- Time zone
- Experience level
- Availability for collaboration and mentoring

---

## Finding Members

Use GitHub issue search and labels to find members with specific skills.

Examples:

### Azure Members

```text
is:issue is:open label:Azure
```

### Microsoft 365 Experts

```text
is:issue is:open label:Microsoft365 label:Expert
```

### Home Assistant Enthusiasts

```text
is:issue is:open label:HomeAssistant
```

---

## Community Expectations

Please:

- Be respectful and welcoming.
- Keep profile information reasonably current.
- Do not post sensitive personal information.
- Use Discord direct messages responsibly.
- Respect time zones and availability preferences.

---

## Updating Your Profile

If your skills, interests, timezone, or availability change:

1. Locate your existing directory issue.
2. Edit the issue or add a comment with updated information.
3. Maintainers may update labels if required.
